 Telegram-бот и REST API сервис для маркетплейса спасения еды (Food Waste / Surplus Food). Интеграция с FastAPI, Web App, уведомления о новых скидках и автоматическая рассылка.
# Food Market Bot & API

Сервис на базе Telegram-бота и REST API (FastAPI) для маркетплейса остатков еды. Проект помогает заведениям общепита реализовывать нераспроданные блюда и наборы со скидкой в конце дня, а пользователям — покупать еду по сниженной цене.

---

## Основные возможности

### Для покупателей
* Поиск предложений с фильтрацией по городам.
* Пошаговое оформление заказа через Telegram (имя, телефон, количество).
* Просмотр истории и статусов оформленных заказов.
* Подписка на уведомления о появлении новых предложений в выбранном городе.
* Интеграция Telegram Web App для открытия веб-версии сайта внутри интерфейса мессенджера.

### Для заведений (Кафе и рестораны)
* Авторизация по коду доступа (CAFE_ACCESS_CODE).
* Пошаговая публикация предложений (название, скидочная и исходная цена, количество, время самовывоза, город).
* Автоматические уведомления владельцу заведения о поступивших заказах с контактными данными покупателя.

### Маркетинг и административные функции
* Автоматическая рассылка информационных сообщений и рекламы по базе пользователей с заданным интервалом (AD_INTERVAL_MINUTES).
* REST API для получения общей статистики по заказам, выручке и комиссии.

---

## Технологический стек

* Python 3.10+
* aiogram 3.x (Telegram Bot Framework)
* FastAPI / Uvicorn (REST API)
* httpx (асинхронный HTTP-клиент)
* SQLite3 (база данных)
* python-dotenv (управление конфигурацией)
